# Definition of Done

Eine Aufgabe gilt als abgeschlossen, wenn:

- [ ] Anforderungen verstanden und umgesetzt
- [ ] Code kompiliert
- [ ] relevante Unit Tests vorhanden
- [ ] relevante Integration Tests vorhanden
- [ ] Fehlerfälle berücksichtigt
- [ ] Eingaben validiert
- [ ] API-Dokumentation aktualisiert
- [ ] Datenbankmigration erstellt, falls erforderlich
- [ ] keine Secrets im Code
- [ ] Logging sinnvoll eingesetzt
- [ ] Code formatiert
- [ ] Commit verständlich benannt
- [ ] README/Dokumentation bei Bedarf aktualisiert
